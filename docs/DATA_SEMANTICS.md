# 数据语义与限制

- Steam游戏库、近期聚合、累计时长样本、成就分别保存。全成就不是剧情通关。每日快照从首次完整同步开始；首日没有趋势基线，负计数回退不补成负游玩时长。
- B站历史按BV/分P保存最后观察，不是每次重看日志；收藏、点赞、投币、稍后再看和关注UP分别表达。点赞缺失时间不拿视频发布时间代替；投币数量取本人字段，不取全站统计。
- 字幕默认只读第一P，可指定cid与语言。字幕时间是视频内秒数。上传未结束时返回partial；没有可用字幕时不伪造文本。
- 网易云红心与歌单收藏不等于每首都喜欢。排行score不等于次数，最近列表时间未经证实时不转换为单次播放事件。歌单曲目依据trackIds逐页获取，不把详情首屏当全量。
- 网易云时长的默认推定口径为周/月及日明细用分钟，总量及年度用秒。保存原始数值和inferred_user_accepted标记；这不是官方已证实的单位，部署者应根据实际接口证据复核。年度足迹不等于完整年度报告。
- 弹弹play的FavoriteStatus：0未看完、1已看完、2放弃，缺失未知。个人评分来自UserRating，不混用社区Rating。示例评分标签是可修改的个人解释，不是平台统一标准。
- 同平台同ID确认同一条目，同网易云专辑ID确认同专辑；Steam官方type=music与fullgame.appid确认游戏→原声应用。标题、艺人或跨语言相似只产生候选，不自动确认跨平台OST。
- 来源未同步、失败、权限不足或历史窗口之外，不能解释为没有行为。时间轴把事件、最后观察、当前状态和统计快照分轨。推荐反馈只保存用户明确表达，不修改平台账号。
- 删除只作用于本服务缓存与相关状态，并暂停来源；不删除平台数据、源数据库、备份或登录凭据。恢复同步也不表示数据已经补齐。
